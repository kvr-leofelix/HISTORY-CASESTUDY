--------------------------
ERROR:
leofelix@leofelix:~/arena$ mv arena/.git .
mv: cannot overwrite './.git': Directory not empty
MESSAGE MEANS:
The error occurs because ~/arena is already initialized as a Git repository, meaning you created a repository inside a repository. You must delete the incorrect outer tracking folder before moving the correct, cloned one up.
```bash
rm -rf .git
```
Delete the incorrect .git tracking folder in your current directory so you can replace it with the correct one linked to your GitHub.
```bash
mv arena/.git .
mv arena/README.md .
```
2.Extract the Cloned Data:Move the Correct Repo.Move the correct .git folder and the README file from the nested folder up to your current location.

3.Fetch and Align History:Synchronization.Pull down the remote history (like the README commits) without overwriting the local files you just structured. Using reset ensures Git aligns its history with the main branch while leaving your actual files completely untouched.
```BASH

git reset origin/main
```
